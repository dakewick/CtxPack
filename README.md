# CtxPack

**CtxPack** 是一款专为开发者设计的 **大型代码库上下文管理工具**。它旨在解决将庞大的本地工程代码喂给本地大模型（LLM，如 Ollama）时，面临的 **上下文窗口超限、数据噪点过多** 导致 AI 分析不准的问题。

CtxPack 是开发者用本地大模型分析大型异构工程的“前置 Token 熔炼炉”。

---

## 核心功能

### 1. 智能源码骨架提取 (Python 驱动)
* **噪点过滤**：自动识别并剔除二进制文件、编译产物、版本控制及纯 UI 坐标布局等低价值业务噪点。
* **结构化提取**：精准抓取 C++ 类定义/信号槽、核心业务方法、脚本函数及常量配置。
* **Markdown 地图生成**：自动生成包含 Mermaid 架构图、核心业务流程摘要及 AI 修改热点指南的 Markdown 文档。

### 2. Token 压缩防御面板
* **效能预估**：内置零依赖高精源码 Token 估算器。
* **可视化数据**：实时展示“原始全量 Token” vs “压缩精炼骨架”的对比矩阵，压榨率通常可达 80% 以上，确保精炼骨架死锁在 AI 的安全视窗内。

### 3. 本地 AI 聊天与 Ollama 深度集成 (Qt/C++ 驱动)
* **动态配置**：无需重启，实时固化 Ollama 服务参数。
* **上下文智能上传**：一键将架构地图作为会话上下文直接提交给 AI 模型。

### 1. 🔍 精准代码雷达 (Code Radar)

* **痛点摧毁**：以往喂给 AI 项目地图后，模型总是靠猜来续写函数。现在，只需在提示词生成器上方输入核心方法名（如 `void example` 或 `def auto_weigh`），雷达会瞬间启动！
* **双核感知匹配**：
* **C++ / QML 模式**：智能跨越类作用域（兼容 `Class::`），内置花括号对齐清洗算法，精准切下整个大括号闭合函数体。
* **Python 模式**：自研缩进对齐匹配（Indent Matching）算法，完美攻克 Python 嵌套定义，不多抓也不漏抓。


* **一键熔炼**：捞出来的真实代码可一键追加入“现有代码日志框”，为大模型提供 100% 真实、零噪点的微观上下文。

### 2. ⚡ CtxPack 智能提示词生成器 (Prompt Gear)

* **专家级结构化组装**：内置三大独立开发齿轮（`Qt 开发`、`嵌入式固件`、`Linux 系统编程`），自动注入架构师设定、环境约束与反幻觉兜底指令。
* **四种极限交付风格**：支持 `补丁模式 (Diff)` [推荐本地小模型]、`极简核心代码`、`完整工程文件` 及 `内核级/寄存器底层剖析`，按需极速输出。
* **赛博朋克 UI 交互**：全套重构的 Cyber 风格组件库（`CyberCheckBox` / `CyberComboBox`），原生适配高强度暗色开发环境。

### 3. 📉 上下文极致压榨

* **Token 防御矩阵**：进一步精简逆向扫描算法，将项目架构信息的 Token 压缩率**稳定维持在 83.3% ~ 93.4% 之间**，将几万 Token 的重工业工程重组为 1000+ Tokens 的黄金骨架，死死捍卫本地 Ollama 显存视窗。

## 🛠️ 底层健壮性重构 (扫雷日志)

为了应对生产环境和跨平台部署的严苛要求，我们对 C++ 核心后端（`CompressorBackend`）进行了彻底的“扫雷重构”：

* **彻底杜绝 UI 假死**：全面重构 `searchCodeRadar`，引入 `QEventLoop` 异步等待机制。即使后台进行高强度文件扫描，前端 UI 动画依然保持 60 帧丝滑。
* **僵尸进程全网超度**：优化任务取消控制流。点击“取消”时，主进程先尝试 `terminate()` 优雅终止，再以 `kill()` 暴力击杀，并同步强制移除生成的临时物理文件，后台内存干净如初。
* **多编码降级回退**：本地文件 I/O 模块新增 `UTF-8 ➔ GBK ➔ Latin-1` 自动编码降级尝试，Windows 平台下带有中文注释的老旧 C++ 文件绝不触发 `UnicodeDecodeError` 崩溃。
* **性能优化**：借助 `clazy` 静态分析器，全盘重构了范围循环中的隐式共享 Detach 陷阱与 `QString` 内存分配，运行效能再度提升。
