# CtxPack

**CtxPack** 是一款专为开发者设计的 **大型代码库上下文管理工具**。它旨在解决将庞大的本地工程代码喂给本地大模型（LLM，如 Ollama）时，面临的 **上下文窗口超限、数据噪点过多** 导致 AI 分析不准的问题。

CtxPack 是开发者用本地大模型分析大型异构工程的“前置 Token 熔炼炉”。

---

## 💡 核心功能

### 1. 智能源码骨架提取 (Python 驱动)
* **噪点过滤**：自动识别并剔除二进制文件、编译产物、版本控制及纯 UI 坐标布局等低价值业务噪点。
* **结构化提取**：精准抓取 C++ 类定义/信号槽、核心业务方法、脚本函数及常量配置。
* **Markdown 地图生成**：自动生成包含 Mermaid 架构图、核心业务流程摘要及 AI 修改热点指南的 Markdown 文档。

### 2. Token 压缩防御面板
* **效能预估**：内置零依赖高精源码 Token 估算器。
* **可视化数据**：实时展示“原始全量 Token” vs “压缩精炼骨架”的对比矩阵，压榨率通常可达 80% 以上，确保精炼骨架死锁在 AI 的安全视窗内。

### 3. 本地 AI 聊天与 Ollama 深度集成 (Qt/C++ 驱动)
* **动态配置**：无需重启，实时固化 Ollama 服务参数。
* **上下文智能上传**：一键将架构地图作为会话上下文直接提交给 AI 模型。

### 4. Git 全生命周期工作流 (v1.3.0 新增)
* **极客控制台**：深度嵌入 IDE 面板，一次扫描提取 本地/远程分支、Hash 及追踪状态。支持历史硬核回溯 (Hard Reset)、分支闭环合并与版本打标封档。

## 📦 部署与运行说明 (Assets)

如果你下载的是源码包或独立发布版本，请遵循以下规范：
1. 运行 `CtxPack.exe` 时，请确保核心解析脚本 **`code_radar.py`** 与 **`extract_skeleton.py`** 始终保持在可执行文件的**同级目录**下，以享受免编译的算法热更新。
2. 推荐使用 CMake 构建工程，源码包已内置标准化的 `CMakeLists.txt`。

## 🚀 最新更新：v1.3.0 (Git 时间机器 · 版本全生命周期闭环)

> 🎯 **“打破「开发→提交→遗忘」的单向诅咒，构建全栈闭环流。”**
> 本次更新首次将完整 Git 工作流深度嵌入 CtxPack 面板，实现从微观变更提取到宏观版本封档的一站式管理。

### ✨ 核心重大升级
* **🕰️ Git 时间机器 (Time Machine)**：
  一键回看最近 10 次提交记录，右键任意历史节点执行 **Hard Reset** 硬核回溯。内置二次确认熔断机制，对误操作零容忍。
* **🔀 分支合并全闭环 (Merge Loop)**：
  分支 CRUD 面板彻底重构，新增 **Merge into Current** 一键合并能力。智能检测合并冲突（CONFLICT），提供「手工解决」与「Abort 撤销」双路径逃生舱。
* **🏷️ 版本封档系统 (Tag Archive)**：
  右键任意提交即可打标签（v1.0.0 / v2.3.1 等），右侧 VERSIONS 面板独立展示全部归档版本。点击版本一键签出，触发 **分离头指针 (Detached HEAD) 强制预警**，杜绝孤立提交丢失。
* **📊 双栏信息指挥塔**：
  HISTORY 面板采用左右分栏设计——左 COMMITS（提交流水线）+ 右 VERSIONS（版本陈列馆）。底层 `for-each-ref` 引擎一次扫描提取 本地/远程分支、Hash、时间戳、ahead/behind 追踪状态，秒级渲染。

### 🛠️ 底层健壮性扫雷重构 (Git Engine)
* **分隔符防御升级**：全量 Git 输出解析弃用管道符 `|`，改用 `%09` 十六进制 Tab 分隔符 + C++ 字面量 `\t` 双保险，分支名含特殊字符绝不裂字段。
* **确认弹框体系化**：统一 `confirmDialog` 弹框引擎。撤销文件、删除标签、切换版本、Hard Reset 四条高危链路全部经过阻断确认，任意误触均被拦截。
* **完美超度僵尸进程**：重写 `runGitCmd` 超时路径，`waitForStarted` 失败时补入 `kill()` 连招，Git 子进程与 Qt 对象双维度清理率达 100%。
* **零假死异步流**：全链路采用 `QProcess` + `QEventLoop` + `QTimer` 超时守护，Git 命令最长阻塞 15s（防冲突挂死），前端 UI 绝不冻结。
* **中文错误友好化**：重构 `friendlyGitError()` 翻译矩阵，覆盖非法分支名/标签名、已存在冲突、未合并删除等极端场景，原始 Git 报错不再直面用户。老版本 Git 完美兼容降级（支持 `symbolic-ref`）。

## 🚀 历史版本：v1.2.0 (Ultimate Fusion & Code Radar)

> 🎯 **“从宏观架构导航，到微观源码定点爆破。”**
> 本次更新是 CtxPack 走向“工业级 AI 辅助工作台”的里程碑式飞跃，彻底终结本地大模型（如 Qwen2.5-Coder）的幻觉与盲猜。

### 1. 🔍 精准代码雷达 (Code Radar)
* **痛点摧毁**：只需在提示词生成器上方输入核心方法名（如 `void example`），雷达瞬间启动提取微观源码。
* **双核感知匹配**：
  * **C++ / QML 模式**：智能跨越类作用域（兼容 `Class::`），内置花括号对齐清洗算法。
  * **Python 模式**：自研缩进对齐匹配（Indent Matching）算法，完美攻克 Python 嵌套定义。

### 2. ⚡ CtxPack 智能提示词生成器 (Prompt Gear)
* **专家级结构化组装**：内置三大独立开发齿轮（`Qt 开发`、`嵌入式固件`、`Linux 系统编程`），自动注入架构师设定、环境约束与反幻觉兜底指令。
* **极限交付风格**：支持 `补丁模式 (Diff)`、`极简核心代码`、`完整工程文件` 及 `底层剖析` 四种模式。
* **赛博朋克 UI 交互**：重构 Cyber 风格组件库（`CyberCheckBox` / `CyberComboBox`），原生适配高强度暗色开发环境。

### 3. 📉 底层重构与效能压榨
* **Token 防御矩阵**：逆向扫描算法再升级，项目地图 Token 压缩率**稳定维持在 83.3% ~ 93.4% 之间**，死死捍卫本地 Ollama 显存视窗。
* **杜绝 UI 假死 & 内存净化**：引入 `QEventLoop` 异步机制，高强度扫描保证 60 帧丝滑；取消任务时采用 `terminate()` + `kill()` 连招，后台内存干净如初。
* **多编码降级回退**：本地 I/O 支持 `UTF-8 ➔ GBK ➔ Latin-1` 自动降级，带有中文注释的老旧工程绝不触发解码崩溃。
