### 软件名称：CtxPack

**CtxPack** 是一款专为开发者设计的**大型代码库上下文管理工具**。它旨在解决将庞大的本地工程代码喂给本地大模型（LLM，如 Ollama）时面临的**上下文窗口超限、数据噪点过多**导致AI分析不准的问题。

它主要包含以下核心功能：

### 1. 智能源码骨架提取 (Python驱动)

* **噪点过滤**：自动识别并剔除二进制文件、编译产物（build/OBJ）、版本控制（.git）及纯 UI 坐标布局等低价值业务噪点。
* **结构化提取**：精准抓取 C++ 类定义/信号槽、C 独立函数/外设函数、Python 类/方法、Shell 脚本函数及配置文件常量。
* **多编码兼容**：内置编码回退机制（优先 GBK），完美兼容含有中文注释的老旧国内单片机源码环境。
* **Markdown 地图生成**：自动生成包含 Mermaid 架构图、核心业务流程摘要及 AI 修改热点指南的 Markdown 文档。

### 2. Token 压缩防御面板

* **效能预估**：内置零依赖高精源码 Token 估算器。
* **可视化数据**：实时计算并展示项目的 **“原始全量 Token 数” ➔ “压缩精炼骨架 Token 数”** 对比矩阵。
* **压榨率统计**：直观展示逆向压榨压缩率（通常可省去90%以上的噪声 Token），确保精炼后的骨架死死锁在本地 AI 的安全视窗范围内。

### 3. 本地 AI 聊天与 Ollama 深度集成 (Qt/C++ 驱动)

* **动态 API 配置**：无需重启软件，即可动态修改并固化本地 Ollama 服务 URL 和 Model 名称（如 `qwen2.5-coder:14b`）。
* **自动上下文上传**：点击“初始化 AI 链接”即可自动将压缩生成的“项目架构地图”作为会话上下文直接提交给目标 AI 节点。
* **历史对话管理**：完整的对话历史流，支持一键清空内存或重置会话。

**总结：** CtxPack 是开发者用本地大模型分析大型异构工程的“前置 Token 熔炼炉”。
